# Add activity marks along a datetime axis

Add activity marks along a datetime axis

## Usage

``` r
geom_activity_rug(data, time = "time", ...)
```

## Arguments

- data:

  Data containing a timestamp column.

- time:

  Timestamp column name.

- ...:

  Arguments passed to ggplot2::geom_rug().

## Value

A ggplot2 layer.
